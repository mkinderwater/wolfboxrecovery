# WolfBox Recovery 2.16

Native Win32 HEVC recovery and JPEG carving with physical mapping evidence, independent video/audio association, coverage reporting and optional orphan-video reconstruction to playable MP4.

### Included
- Windows C sources and application resource files
- Reproducible Windows build scripts
- Targeted orphan HEVC extraction and FFmpeg-based MP4 export
- Documentation covering sample mapping, physical provenance and recovery limits

### Release availability
This source package contains no prebuilt `.exe`. Windows binaries are published as separate release assets only after the Windows GitHub Actions build passes. This release is provided without a fresh full-card acceptance run. Check results with your own media before relying on any recovered footage.
